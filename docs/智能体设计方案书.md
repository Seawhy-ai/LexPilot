## 一、场景描述

### 1.1 痛点

据统计,我国公众法律素养整体偏低,大量日常纠纷(劳动报酬、租房退押、消费维权、民间借贷、交通事故、婚姻财产等)本可通过合法途径低成本解决,但多数人因**不了解法律依据、不清楚维权流程、不知道找谁求助**而选择隐忍或走极端。专业法律咨询门槛高(一次数百到数千元),普通公众难以负担;搜索引擎给出的回答鱼龙混杂,难以判断是否可靠。

与此同时,高校承担着提升大学生法律素养的社会责任,公众对「听得懂、用得上」的免费法律知识有真实需求。

### 1.2 目标用户

- **在校大学生**(第一用户群体):兼职劳动、租房、校园贷陷阱、实习合同等高频场景;
- **普通社会公众**:劳动、消费、房产、婚姻家庭、交通事故等常见纠纷当事人;
- **普法工作者 / 社区工作者**:作为日常普法答疑的辅助工具。

### 1.3 公益定位

- 面向公众**免费开放**法律知识咨询,降低获取门槛;
- 回答坚持「**大白话解释 + 法条引用 + 维权渠道指引**」三位一体;
- 明确**边界**:本智能体仅提供普法信息,不替代执业律师意见,重大事项引导用户拨打 **12348 法律援助热线**或联系属地法律援助机构;
- 体现「教育普惠」的公益维度,对接 12348 / 12315 / 劳动仲裁等公共维权资源。

## 二、智能体拟实现的核心功能

### 功能总览

| 编号 | 功能 | 说明 | 对应 FastGPT 能力 |
|---|---|---|---|
| F1 | 场景化法律问答 | 按生活场景提问,大白话回答 + 法条引用 | 知识库检索 + AI 对话 |
| F2 | 领域识别与分流 | 自动识别劳动/消费/婚姻/房产/借贷/交通等领域 | 问题分类节点 |
| F3 | 案情要素引导 | 多轮追问收集关键事实(如合同是否签订、入职时长) | 对话变量 + 记忆 |
| F4 | 维权路径指引 | 按领域给出仲裁/投诉/诉讼的具体渠道与材料清单 | 条件分支 + 知识库 |
| F5 | 文书模板速查 | 借条、劳动合同要点、租房合同注意事项等模板 | 知识库文档 |
| F6 | 普法案例库问答 | 基于公开指导案例的问答式普法 | 知识库检索 |
| F7 | 免责与转介 | 自动附带免责声明,重大事项转介法律援助 | 知识库 + 固定回复 |

### 核心工作流设计(以「劳动纠纷」为例)

```
用户提问:「公司拖欠我两个月工资怎么办?」
  │
  ▼ 问题分类节点:识别 → 劳动纠纷
  │
  ▼ 案情要素引导(对话变量):是否签订劳动合同? 在职还是已离职?
  │
  ▼ 知识库检索:劳动合同法 §30、§85;劳动法 §50;劳动争议调解仲裁法相关条文
  │
  ▼ AI 对话节点:大白话解释拖欠工资的法律性质与责任
  │
  ▼ 条件分支:已离职 → 指引劳动仲裁(时效 1 年、需材料清单)
  │            在职 → 指引劳动监察投诉(12333)+ 保留证据建议
  │
  ▼ 汇总输出:法条引用 + 分步骤维权指引 + 免责声明 + 12348 转介
```

其余领域(消费维权、婚姻家庭、房产租赁、民间借贷、交通事故)复用同一条「分类 → 要素引导 → 检索 → 解答 → 分支指引」主干,通过**领域知识库分库 + 分类条件**差异化配置。

## 三、所使用的知识文档与数据来源

| 数据类型 | 来源 | 说明 |
|---|---|---|
| 民法典及常用单行法全文 | 国家法律法规数据库(npc.gov.cn)等公开渠道 | 民法典、劳动法、劳动合同法、消费者权益保护法、劳动争议调解仲裁法、道路交通安全法、婚姻家庭编司法解释等 |
| 最高法指导案例 / 公报案例 | 最高法官网、裁判文书公开信息 | 脱敏、节选,用于普法案例问答 |
| 高频 FAQ 知识库 | 自建(基于 12348 常见咨询问题与律所公开普法资料整理) | 覆盖 30+ 个高频生活场景,每条含「结论 / 依据 / 操作步骤 / 注意事项」 |
| 维权渠道信息 | 12348、12315、12333、劳动仲裁机构等官方公开信息 | 全国热线、属地机构、材料清单 |
| 法律文书模板 | 自建整理(借条、租房合同要点、劳动合同注意事项等) | 仅做提示模板,注明「非合同、签约前请咨询律师」 |
| (可选)LexPilot 题库沉淀 | 本项目团队此前开发的学习工具中的民/刑知识点 | 经审核后用于普法常识问答 |

> 版权与合规:全部采用公开法律文本与公开案例,文档标注来源;不采集用户个人信息,对话数据本地化部署不落库留存,符合《个人信息保护法》与公益服务合规要求。

## 四、基于开源智能体搭建平台的技术可行性说明

### 4.1 平台选型:FastGPT(开源)

- **开源可私有化部署**:FastGPT 为开源项目,学校已提供平台环境,数据自主可控、无需额外采购,符合「开源共享」宗旨;
- **零模型门槛**:对接国产大模型(如 DeepSeek、智谱 GLM、通义千问等),API 成本极低,公益场景可长期免费运行;
- **前端零开发**:平台自带对话界面与一键分享链接,支持嵌入网页,普通公众无需安装即可使用,天然契合公益的低门槛诉求。

### 4.2 四大核心能力与比赛考核点一一对应

| 比赛考核点 | FastGPT 对应能力 | 本项目落地方式 |
|---|---|---|
| **知识库构建** | 文档切分、Web 爬取、定时同步、混合检索、多库隔离 | 法条/案例/FAQ/渠道 4 个知识库分库管理,支持定期更新法条 |
| **工作流编排** | 问题分类、条件分支、对话变量、AI 对话、文本拼接、代码执行 | 「分类 → 要素引导 → 检索 → 解答 → 分支指引」主干工作流 |
| **工具集成** | HTTP 请求、自定义插件、OpenAPI 工具 | 预留对接公开法律法规数据库接口;维权渠道信息查询工具 |
| **测试优化** | 测试集自动化评估、调试日志、数据集对比 | 建立 100+ 条真实场景测试集,按正确率迭代提示词与知识库切分 |

### 4.3 技术难点与解决方案

| 难点 | 解决方案 |
|---|---|
| 法律回答严谨性 | 回答强制要求引用法条编号 + 附带免责声明;知识库分库避免跨领域混答;测试集覆盖高频场景把关 |
| 多轮案情收集 | 用对话变量 + 条件分支引导用户补充关键事实,避免「一次问到底」的机械感 |
| 知识库时效性 | 法条更新采用定期重新同步;标注「以最新法律法规为准」 |
| 公益场景并发与成本 | 私有化部署 + 国产低成本模型,单次咨询成本可忽略 |

### 4.4 可扩展性

- 新领域 = 新增知识库分库 + 分类节点扩展,不改主干;
- 可扩展对接学校法律援助中心、12348 属地资源形成转介闭环;
- 可嵌入高校官网/公众号/社区小程序,形成持续服务的公益入口。
