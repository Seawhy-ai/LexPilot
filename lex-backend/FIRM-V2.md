# 律所经营第二版

首页为可横向拖动的十级律所场景，点击接待区、图书室、会议室、档案室、休息区打开设施；点击人物进入档案。自由摆放模式可先选择设施，再点击空白场景保存设施交互点位置。底部为律所、委托、团队、经营四个入口。使用已有生成式美术资源，采用深蓝、暖木、金铜配色，无 emoji 控件。

## 玩法

- 十二名候选人，D/C/B/A/S五档，校园、社会、猎头三种招聘。报价公开，签约即入职。每渠道每经营日首刷免费，之后30资金。猎头需4级、30声望。
- 初始免费实习生林知夏；团队容量为律所等级+2。五项能力、30级成长、3/6/9/12级职位晋升、专项训练、精力和信任。信任20解锁个人故事，一次性奖励专长与声望。
- S级天赋：全局声望+5%、基础资金+5%、调查证据提示、谈判能力+10%、同组经验+10%、公益声望+15%。管理席位1/2/3个分别在1/5/8级开放；全局天赋须任命，参战天赋须安排到案件组，同名不叠加。
- 六个原创教学委托：社区咨询、合同争议、欠薪追索、家事协商、刑事准备、行政救济。每案五阶段，各有具体决策与法律解释。所长可独立承办，或安排两名成员；正确准备、能力匹配、设施、专业路线和天赋共同影响结果，无随机胜诉机制。
- 接案消耗15精力。结案获得资金、声望、经验、信任及满意度。档案室最多支持三案并行，同一成员不可同时办理两案。
- 五类设施各三级。三种装修免费切换，十级律所沿用已有分级场景。3级开放专业发展路线，对应案件资金+10%。
- 每经营日一个可选择事件，结案档案保留15份、经营日志20条，控制云档案体积。
- 至少结案一次且清空在办案件才能主动结束经营日，届时结算工资和恢复精力。离线不扣薪。资金不足记为待付工资，基础案件仍可承办；招聘、培训、晋升、设施与律所扩张暂停，补薪后恢复。
- 运营补贴按北京时间自然日每日100。积分兑换沿用后端原子兑换接口。工资和其他经营数值通过现有云档案版本机制保存。
- 周榜按UTC周一换周，与服务器一致。公益贡献按当周公益声望，客户满意度按当周结案平均值，至少3案才参与满意度榜。排行榜读取用户云档案，属于休闲养成榜，不提供竞技反作弊保证。

## 兼容与上线

旧资金、声望、律所等级、结案数、装修保留；旧assistant/lawyer/partner对应陈书言/周砚/苏晚晴，另有初始林知夏。旧在办委托保留为待结算项。迁移在首次进入律所时保存到当前账号。

新增资源：firm-engine.js、firm-v2.js、firm-v2.css。保留原firm-game.js作为旧入口兼容，新界面在其后加载。部署脚本只追加新资源标签，保留线上其他页面改动。

执行 `sudo bash deploy-firm-v2.sh`。先完整下载并校验清单、检查语法，然后备份代码及使用SQLite VACUUM INTO生成一致性数据库备份。先部署兼容后端并检查health，再安装前端与更新缓存版本。发生错误恢复原代码；不自动恢复数据库，以免覆盖部署期间正常写入的数据。

验证：`node --test lex-backend/firm-test.mjs lex-backend/test.mjs`；启动8767静态服务后执行 `node lex-backend/ui-test.cjs`。
